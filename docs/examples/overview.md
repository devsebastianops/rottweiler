# Examples

This section provides real world examples of how to use Rottweiler to validate policies against input data.

- [Terraform Plan Validation](terraform-plan-validation.md): Sometimes, you want to validate your Terraform plan before applying it. This example shows how to use Rottweiler to check a Terraform plan against a set of policies.
- [GitHub Workflow Validation](ci-cd-pipeline-validation.md): In a CI/CD pipeline, you might want to validate your configuration files before deploying them.
- [Docker Compose Check](docker-compose-check.md): An example of how to validate a Docker Compose file against a set of policies.
- [Swagger / OpenAPI Governance](swagger-openapi-governance.md): When working with APIs you might want to enforce certain rules on your Swagger or OpenAPI specifications. This example shows how to use Rottweiler to validate an OpenAPI specification against a set of policies.
- [Package Governance](package-governance.md): This example shows how to use Rottweiler to enforce rules on npm package.json files.
